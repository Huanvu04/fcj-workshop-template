Trong quá trình thực tập tại **First Cloud Journey (AWS Study Group)**, mình đã hoàn thành chương trình thực tập trong **12 tuần**. Mỗi tuần tập trung vào một chủ đề khác nhau, kết hợp giữa học lý thuyết, thực hành các bài Lab và tìm hiểu các dịch vụ trên nền tảng AWS nhằm nâng cao kiến thức, kỹ năng thực hành và kinh nghiệm làm việc với các dịch vụ điện toán đám mây của AWS.

* **Tuần 1:** [Onboarding và làm quen với AWS](1.1-week1/) Làm quen với chương trình First Cloud Journey, hoàn thành các nhiệm vụ nhận AWS Credits, học Module 01 và thực hành các Lab đầu tiên về AWS Console, AWS CLI và Amazon EC2.

* **Tuần 2:** [Mạng trên AWS (Amazon VPC)](1.2-week2/) Tìm hiểu Amazon VPC, Subnet, CIDR, Route Table, VPN, Security Group và Network ACL để xây dựng nền tảng về kiến trúc mạng trên AWS.

* **Tuần 3:** [AWS Budgets và Amazon EC2](1.3-week3/) Hoàn thành Lab 07, tìm hiểu AWS Budgets, AWS Support và các kiến thức cơ bản về Amazon EC2.

* **Tuần 4:** [Networking trên AWS](1.4-week4/) Tìm hiểu Internet Gateway, NAT Gateway, Elastic IP và hoàn thành nội dung Module 03.

* **Tuần 5:** [Amazon Route 53 và SSH](1.5-week5/) Hoàn thành Lab 19, Lab 20, tìm hiểu Amazon Route 53 và thực hành kết nối SSH đến EC2 Instance.

* **Tuần 6:** [Amazon S3 và AWS Backup](1.6-week6/) Hoàn thành Lab 13, tìm hiểu Amazon S3, AWS Backup và thực hành khôi phục dữ liệu (Test Restore).

* **Tuần 7:** [Amazon S3 Storage Classes](1.7-week7/) Hoàn thành Module 04, nghiên cứu Lab 57 và tìm hiểu các lớp lưu trữ của Amazon S3.

* **Tuần 8:** [Static Website Hosting trên Amazon S3](1.8-week8/) Hoàn thành Lab 57, triển khai Static Website Hosting, tìm hiểu Bucket Policy và S3 Versioning.

* **Tuần 9:** [AWS Backup nâng cao](1.9-week9/) Thực hành Backup Vault, Backup Plan, Notification, Test Restore và chuẩn bị cho Lab 14.

* **Tuần 10:** [AWS Storage Gateway](1.10-week10/) Hoàn thành Lab 14, Lab 24, tìm hiểu AWS Storage Gateway, File Gateway và đồng bộ dữ liệu giữa File Gateway với Amazon S3.

* **Tuần 11:** [Amazon FSx và File System](1.11-week11/) Hoàn thành Lab 25, tìm hiểu Amazon FSx, triển khai SSD/HDD Multi-AZ File System, cấu hình File Share và đánh giá hiệu năng hệ thống.

* **Tuần 12:** [AWS Security Services](1.12-week12/) Hoàn thiện Workshop, đăng bài blog chia sẻ kiến thức, hoàn thành Lab 57 và tìm hiểu các dịch vụ bảo mật như IAM, Cognito, AWS Organizations, IAM Identity Center (SSO) và AWS KMS.
