During my internship at **First Cloud Journey (AWS Study Group)**, I completed a **12-week** training program. Each week focused on a different AWS topic, combining theoretical learning, hands-on labs, and practical experience with AWS services to strengthen my cloud computing knowledge and practical skills.

* **Week 1:** [Onboarding and AWS Fundamentals](1.1-week1/) Joined the First Cloud Journey program, completed AWS Credits tasks, studied Module 01, and practiced using AWS Console, AWS CLI, and Amazon EC2.

* **Week 2:** [AWS Networking (Amazon VPC)](1.2-week2/) Learned about Amazon VPC, Subnets, CIDR, Route Tables, VPN, Security Groups, and Network ACLs to build a solid foundation in AWS networking.

* **Week 3:** [AWS Budgets and Amazon EC2](1.3-week3/) Completed Lab 07, explored AWS Budgets, AWS Support, and the fundamental concepts of Amazon EC2.

* **Week 4:** [AWS Networking Components](1.4-week4/) Studied Internet Gateway, NAT Gateway, Elastic IP, and completed the theoretical content of Module 03.

* **Week 5:** [Amazon Route 53 and SSH](1.5-week5/) Completed Labs 19 and 20, learned Amazon Route 53, and practiced connecting to Amazon EC2 instances via SSH.

* **Week 6:** [Amazon S3 and AWS Backup](1.6-week6/) Completed Lab 13, explored Amazon S3, AWS Backup, and practiced backup and restore operations.

* **Week 7:** [Amazon S3 Storage Classes](1.7-week7/) Completed Module 04, studied Lab 57, and learned about Amazon S3 Storage Classes.

* **Week 8:** [Static Website Hosting on Amazon S3](1.8-week8/) Completed Lab 57, deployed a static website on Amazon S3, and explored Bucket Policies and S3 Versioning.

* **Week 9:** [Advanced AWS Backup](1.9-week9/) Practiced Backup Vaults, Backup Plans, Backup Notifications, Restore Testing, and prepared for Lab 14.

* **Week 10:** [AWS Storage Gateway](1.10-week10/) Completed Labs 14 and 24, learned AWS Storage Gateway, deployed File Gateway, and synchronized data with Amazon S3.

* **Week 11:** [Amazon FSx and File Systems](1.11-week11/) Completed Lab 25, explored Amazon FSx, deployed SSD and HDD Multi-AZ File Systems, configured File Shares, and performed storage performance testing.

* **Week 12:** [AWS Security Services](1.12-week12/) Finalized the architecture diagram and workshop, published a technical blog, completed Lab 57, and explored AWS security services including IAM, Amazon Cognito, AWS Organizations, IAM Identity Center (SSO), and AWS Key Management Service (KMS).
