This section summarizes the AWS blog posts I have read, studied, and rewritten during my internship to expand my understanding of cloud architecture and AI technologies beyond the training materials.

### [Blog 1 - AWS Architecture Blog | What I Learned from S&P Global's Disaster Recovery Strategy](3.1-Blog1/)

This blog summarizes how S&P Global designed a Disaster Recovery solution using Amazon FSx for NetApp ONTAP, SnapMirror, Snapshots, and FlexClone to minimize downtime while ensuring data availability.

### [Blog 2 - Claude Apps Gateway for AWS – What I Learned from the AWS Machine Learning Blog](3.2-Blog2/)

This blog introduces Claude Apps Gateway for AWS and explains how organizations can centrally manage authentication, policy enforcement, monitoring, request routing, and cost governance when deploying AI applications.

Through reading and writing these blog posts, I not only strengthened my understanding of AWS services but also improved my ability to research, analyze, and summarize technical documentation.

###  [Blog 3 - Building Highly Available Oracle Databases with Amazon FSx for NetApp ONTAP – Insights from AWS Architecture Blog](3.3-Blog3/)
This article analyzes how to combine Amazon FSx for NetApp ONTAP Multi-AZ, Synchronous Replication, and an automation pipeline (EventBridge, Lambda, SSM) with an Auto Scaling Group to build a self-healing architecture that optimizes RTO and RPO metrics for Oracle Database systems.

###  [Blog 4 - Query Amazon S3 Access Logs Instantly: Goodbye Log Cleanup Nightmare – Insights from AWS Storage Blog](3.4-Blog4/)
This article introduces an automated solution for log management by delivering Amazon S3 Access Logs directly to CloudWatch Logs and S3 Tables, enabling developers to query data instantly via CloudWatch Logs Insights without building and maintaining complex data pipelines.
