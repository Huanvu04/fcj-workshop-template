# Event Report: “FCAJ Meetup - Career Development, System Design & DevOps on AWS”

### Event Objectives

- Explore System Design principles and scalable application architecture on AWS.
- Learn about the roles, responsibilities, and career paths of Data Analytics Engineers, DevOps Engineers, and Cloud Engineers.
- Gain practical insights into working in multinational companies and modern software development environments.
- Discover AWS community programs and opportunities for continuous learning and professional growth.

#### System Design on AWS

- Designing a scalable URL Shortening Service.

- Exploring AWS services for building highly available cloud applications.

#### Data Analytics and Career Development

- Understanding the responsibilities of a Data Analytics Engineer.
- Developing essential skills such as Critical Thinking, Communication, Storytelling with Data, and Problem Solving.
- Learning about recruitment processes and workplace culture in multinational companies.
- Exploring career development from Follower to System Thinker.

#### DevOps in Real-World Projects

- Understanding the actual responsibilities of a DevOps Engineer.
- Learning essential technologies including Linux, Networking, Git, CI/CD, Containers, and Cloud Computing.
- Adopting automation and system-thinking principles.
- Learning practical approaches to troubleshooting and collaboration.

#### Career Growth through the AWS Community

- Introduction to AWS Student Builder Group and AWS Community Builder.
- Career development from First Cloud Journey to AWS Partner.
- Building a professional network and personal brand.
- Opportunities for continuous learning and career advancement within the AWS ecosystem.
